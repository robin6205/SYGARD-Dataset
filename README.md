# SYGARD Dataset

Dataset instances are kept in separate folders.

- [ORD, September 28, 2026, 18:00–18:05 UTC](ord_2026-09-28_1800z/README.md): a three-camera Unreal replay with simulation reference tracks and camera-derived aircraft tracks.
- [ORD aircraft, 3 Hz](ord_aircraft_2026-09-28_1800z_3hz/README.md): the same five-minute ADS-B traffic replay, with complete actor and camera tracks at their recorded timestamps.
- [ORD drone, 3 Hz](ord_drone_2026-09-28_1800z_3hz/README.md): one synthetic drone route from east of the airport toward its center, with complete actor and camera tracks at their recorded timestamps.

Each instance README describes its files, coordinates, and limits.
